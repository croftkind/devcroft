# Terminal

Terminal-backed tabs own independent PTY sessions. Switching tabs keeps the underlying process alive. Devcroft starts the default shell as an interactive login shell, then enters the Agent or Neovim command through that shell. This makes shell startup files, environment changes, aliases, functions, and tool-manager activation available to those commands.

## Separate work and personal agent accounts

In **Settings → Spaces → Agent accounts**, enable separate accounts for the spaces that need their own subscriptions. Existing spaces use shared machine accounts until you enable this option. Close the space's open agent sessions before changing the setting or deleting the space.

For example, enable separate accounts for Work and Personal, open a Work repository, choose Claude in **New session**, and sign in with your company account. Then open a Personal repository and sign in with your personal account. Subsequent managed agent launches and resumes use the repository's space automatically, including when browsing **All**. Each agent requires its own first login on each device. In Claude, use `/status` to check the selected account before starting work.

Separate accounts have their own local agent directories, settings, and history. Existing shared credentials and conversations are not copied. Renaming a space keeps its account identity; disabling isolation retains its local data for re-enabling. Deleting a space moves repositories to the destination's account selection and leaves the old local agent data intact. Close a repository's open agent sessions before moving it to another space. If an external edit or sync changes ownership while a session is running, it keeps its original account; close it and start a new session. Devcroft refuses to restore a retained pane or resume history from the previous account.

The directory overrides are `CLAUDE_CONFIG_DIR` (and `ANTHROPIC_CONFIG_DIR`) for Claude, `CODEX_HOME` for Codex, and the XDG data/config/state/cache directories for OpenCode. Devcroft stores these under the machine-local `agent-accounts/` directory beside `portable/`; only an opaque account ID and the setting are synced. OMP uses a stable `OMP_PROFILE` for its own isolated authentication, settings, and caches, plus `PI_CODING_AGENT_DIR` for local session storage. OMP's profile data remains in its own machine-local profile directory. OMP history remains managed by OMP, since Devcroft does not yet list its past sessions.

The account environment is applied after login-shell startup, and common inherited agent API keys and subscription tokens are removed for isolated launches. Ordinary Terminal tabs keep their normal environment. This selects account storage; it does not create an OS security sandbox. Provider project settings, custom launch wrappers, and organization policies still apply, and the provider controls which subscription a sign-in can access. Settings → Agent → Skills manages the shared installation; install any desired user skills separately in an isolated agent's directory.

Use current agent CLI versions. [Claude documents that a custom configuration directory also scopes macOS Keychain credentials](https://code.claude.com/docs/en/authentication#credential-management); [Codex documents its credential storage options](https://learn.chatgpt.com/docs/auth#credential-storage).

The terminal UI bundles JetBrains Mono NL Nerd Font Mono v3.5.1 (regular, bold, italic, and bold italic), so Nerd Font symbols work without a separate system font installation. Attribution and license files are in [`assets/`](../assets/).

ANSI faint text uses half opacity, making agent placeholders and suggestions visibly dimmer than typed input. Foreground and background color queries report the terminal's rendered colors so applications can choose matching input backgrounds.

The renderer supports ANSI color, keyboard input, bracketed paste, focus, resizing, scrollback, and scroll-wheel reporting to full-screen applications. Keyboard input automatically returns a scrolled terminal viewport to the active prompt. Each terminal row is shaped as one GPUI text layout with Ghostty styles applied as highlights. Mouse clicks, releases, drags, and hover are forwarded when the terminal application requests them. Hold **Shift** while dragging to select and copy text locally; double/triple-click selects a word/line. **Ctrl-click** (**Cmd-click** on macOS) opens HTTP(S) links, including OSC 8 links. Plain-text URL detection currently covers a single displayed row. Image protocols are not yet supported. The Ghostty binding is pinned to a reviewed upstream revision so builds remain reproducible.
